# Alura Store Challenge

Este proyecto es parte del desafío **Alura Store**, donde se realiza un análisis de rendimiento de cuatro tiendas en línea para ayudar al Sr. Juan a decidir cuál tienda debería vender. El análisis cubre varios aspectos clave como:

- **Facturación total** de cada tienda.
- **Categorías de productos** más y menos vendidas.
- **Calificaciones promedio** de los clientes.
- **Productos más y menos vendidos**.
- **Costo promedio de envío** por tienda.
- **Distribución geográfica de las ventas** utilizando coordenadas de latitud y longitud.

Se utilizan herramientas como **Python**, **Pandas**, y **Matplotlib** para procesar los datos y generar gráficos de análisis visual, como **mapas de calor** y **gráficos de dispersión**.

## Estructura del Proyecto

- **data/**: Archivos CSV con los datos de las tiendas.
- **notebooks/**: Cuadernos de Jupyter con el análisis y visualización de datos.
- **scripts/**: Scripts de Python para el procesamiento de datos y generación de gráficos.
